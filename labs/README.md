# C101 labs

These labs use C and the `dcc` compiler. Start with Lab 01 if you have never
compiled or submitted a program on the YIA server. Finish the core exercises
in Lab 02 before moving on to Lab 03.

| Lab | Topic | Start here |
| --- | --- | --- |
| [01](01/README.md) | Terminal, compiling and submitting | Lab greeting |
| [02](02/README.md) | Input, integer arithmetic and decisions | Scoreboard total, Temperature check, Share the cards |
| [03](03/README.md) | While loops and combining loops with decisions | Launch countdown, Even numbers, Tile pattern |

The examples show exactly what your program should print. Lines in an **Input**
block are what you type after starting the program. Do not add input prompts
unless the exercise asks for one. End each output line with a newline.
Autotests treat compiler warnings as errors. You can check the same rule
when compiling by adding `-Werror` to your `dcc` command.

The activity names in these handouts are for C101 on the YIA server. Your
tutor will tell you when the exercises are available for autotesting and
submission.
